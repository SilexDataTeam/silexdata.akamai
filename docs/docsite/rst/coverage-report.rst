Coverage Summary
=================

This page is regenerated during CI (see the shared ``reusable-docs.yml``
workflow's "Generate coverage summary page" step, which runs the
``coverage-summary`` composite action from
`silexdata.collection_skeleton <https://github.com/SilexDataTeam/silexdata.collection_skeleton>`_)
from that build's coverage data. If you're seeing this placeholder, the
generation step didn't run - view the `latest published coverage report
<https://silexdatateam.github.io/silexdata.akamai/coverage/>`_
instead.
